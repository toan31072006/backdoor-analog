# Experiment preflight for this repository

Before planning, editing, launching, packaging, or reporting an MM-Fi / WiFi-CSI
pose-backdoor experiment, read
`remote_linux/MMFI_CVPR_EXPERIMENT_PLAN_20261015.md`, especially Sections 0, 4,
and 5. This is the user's confirmed experiment plan, not permission to launch a
job or push code.

For each proposed run, check the table ID, method/control rows, dataset/split,
seed, training configuration, evaluation doses, required metrics, and artifact
availability against that note. State any mismatch before the run. Do not call
an incomplete or changed experiment the planned paper table; label it
exploratory until the user approves a revised plan. Never substitute clean PCK
for Target-PCK, omit a baseline or clean reference silently, or select methods
after seeing their scores.

Preserve existing runs and results. A new plan or correction does not authorize
deleting or rewriting historical artifacts.
